### 📦 Open source

**[liquidglass_light](https://pub.dev/packages/liquidglass_light)** · Flutter package

A gyroscope-reactive Liquid Glass border widget — simulates real-time light refraction and specular highlights using `CustomPainter` and `ValueNotifier`, with zero widget tree rebuilds during animation. Supports glassmorphism via optional background blur, refraction intensity, glow, and thickness controls.
