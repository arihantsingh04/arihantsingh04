### 📦 Open source — liquidglass_light

A Flutter package published on pub.dev: a **gyroscope-reactive Liquid Glass border widget** that simulates real-time light refraction and specular highlights using `CustomPainter` and `ValueNotifier`. Zero widget tree rebuilds during animation. Supports glassmorphism via optional background blur, refraction intensity, glow, and thickness controls.
